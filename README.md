# SQL Assignment
This is a practice exercise performing SQL queries to check my knowledge and skills with various SQL question so to improve and enhance learning process

## Assignment 1
1. Create a table (any name of your choice) with column name :-
	a) emp_id
	b) emp_name
	c) designation
	d) salary
2. Insert 5 rows of data as per your wish.
3. Update salary of 4th emp in the above table to (salary + 1000).
4. Delete designation column from the table.
5. Delete one row which is having the least salary.
6. Delete all data from the table.
7. Drop the whole table.

## Assignment 2
1. Find out the customers name where name starts with A and ends with n.
2. Give the orders details where order date is after 2023.
3. Find out the customer whose name is having 3rd letter as ‘a’ and 4th letter as ‘d’.
4. Give the order_id , product_id , product_name, order_date and discount where order date is between June 2022 till November 2022.
5. Find out the customer whose name contains the word ‘Apple’.
6. Details for the order_id after June 2024 where ship_mode is either cash or pay later.
7. Find out the customer whose name does not start with ‘B’ and end with ‘ey’.
8. Retrieve the details of order_id, order_date, and ship_date for orders placed on 20th June 2023, and return the top 2 records sorted by highest profit.
9. Retrieve the details where ship_mode is cash and no discount is given also quantity is either 3 or 7.
10. Retrieve the details where profit > 100 and quantity is between 2 and 5.

## Assignment 3
1. Set city as null for 3 order_ids.
2. Find the order_id , product_id , category , sub_category where the city is null.
3. Find out the latest order_date and first order_date in every payment method.
4. Find out the latest ship_date for every category and also total profit for every category
5. Find the total quantity sold for each sub_category.
6. Find the emp_id where products like Biscuit and Chips having same number of quantity sold from table named sales_data
7. Find the bottom 5 sub_category in West region by total quantity sold
8. Find the total sales for each region and payment_method combination for product ordered in year 2023.
9. Find the order_ids where average of profit is greater then maximum profit.
10. Find the customer name where total quantity purchased by customer equals to the average quantity bought by all the customer.
